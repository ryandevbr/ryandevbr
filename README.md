## Projeto em destaque

### Alerta Enchente CDV — Sistema de Apoio à Decisão

Sistema de alerta antecipado de cheias do Rio Piracicaba para a comunidade de Cachoeira do Vale (Timóteo/MG). Combina dados públicos da ANA e da CEMIG com automação em nuvem para entregar até 10 horas de antecedência antes que uma onda de cheia chegue ao bairro.

**Stack:** Python, PostgreSQL, Supabase, GitHub Actions, HTML/JavaScript

[Repositório](https://github.com/ryandevbr/alerta-enchente-cdv) · [Site em produção](https://alertaenchentecdv.app)
